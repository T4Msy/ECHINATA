# Praça Américo Ferreira de Abreu: História e Convivência

Site estático (HTML, CSS e JavaScript, sem dependências de build) sobre a praça do bairro Santa Mônica, em Uberlândia (MG).

## Seções
1. **A origem e o homenageado**: criação nos anos 1970 e a trajetória de Américo Ferreira de Abreu.
2. **O coração cultural e religioso do bairro**: paróquia, Julinão, feiras e ações sociais.
3. **Memórias vivas da comunidade**: relatos de moradores.
4. **Transformações, desafios e o futuro**: comparativo 2007 × 2026, desafios e automação urbana.

## Como visualizar
Abra `index.html` no navegador, ou rode um servidor local:

```bash
python3 -m http.server 8000
```

## Imagens
Coloque as figuras do relatório em `img/` com os nomes listados em [`img/LEIAME.md`](img/LEIAME.md). Imagens ausentes aparecem como espaços reservados com legenda.
